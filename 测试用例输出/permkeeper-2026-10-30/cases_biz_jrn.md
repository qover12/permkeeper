# PermKeeper 测试用例 · 业务功能域 SET ＋ 端到端旅程域 JRN

- 项目：PermKeeper（Zygisk 模块，清数据后恢复应用设置）
- 版本：工作区 `6e2ca13`（2026-10-30）
- 设备：一加 PLU110 / ColorOS 16 / Android 16（SDK 36）/ `3B663C00LY900000`
- 规则来源：同目录 `rules.md`（第 4 列只引用其中已存在的 ID，不新增规则）
- 用例数：SET 15 条（001–015）、JRN 8 条（001–008），合计 23 条
- 表内 `<br>` 表示该列内的换行（Markdown 表格不能直接换行）
- 第 12、13 列为执行期回填，生成阶段留空

## 通用约定（多条目复用，不在每条里重复）

- **W**：打开 WebUI（KsuWebUI `io.github.a13e300.ksuwebui` → PermKeeper 页面）
- **GET**：`adb shell su 0 sh /data/adb/modules/permkeeper/permkeeper.sh get`
- **PUT**：`adb shell "su 0 sh /data/adb/modules/permkeeper/permkeeper.sh put" < cfg.json`（stdin 传 JSON）
- **LOG**：`adb logcat -c` 后 `adb logcat -v time -T 1 \| Select-String -Pattern "clear-data|config load|baseline|export|rom="`（**必须实时**，见 R-ENV-01：事后 `logcat -d` 可能为 0 条）
- **CLEAR**：`adb shell su 0 pm clear <pkg>`（必须经 su，见 R-ENV-02）；**会丢登录态**
- **MTIME**：`adb shell su 0 stat -c '%y' /data/system/permkeeper/config.json`
- 元素 id 全部取自 `webroot/index.html`（如 `catPermissions`、`btnUncheckAll`、`scopeAll`、`pCancel`、`cdlgYes`）
